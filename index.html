Alcohol Detection System

An IoT-based safety system designed to prevent accidents by detecting alcohol consumption in vehicle operators. It utilizes an MQ-3 Alcohol Sensor and Arduino Uno to monitor breath alcohol levels accurately in real-time. If alcohol is detected above safe limits, the system automatically blocks vehicle ignition via a relay module. Integrated buzzers and LEDs provide immediate visual and auditory alerts to the driver for enhanced safety. This hardware project promotes responsible driving habits and offers a reliable solution for global road safety.
